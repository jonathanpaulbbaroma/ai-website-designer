# AI Website Design Director

AI-powered website design direction and project management platform.

## Architecture

- Laravel
- Inertia.js
- React
- Tailwind CSS
- MySQL
- OpenAI API
- Figma / Figma Make
- Figma MCP
- Git / GitHub

## Purpose

The application acts as an AI senior website designer, UX/UI designer,
visual designer, and creative director.

It guides website projects from requirements and design strategy through
design decisions, Figma generation, approval, and implementation handoff.
